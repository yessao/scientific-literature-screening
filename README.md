# Scientific Literature Screening
This repository contains a small, reusable workflow for screening scientific records with a language model while keeping a physicist in charge of the final decisions. The example task is to select papers on superconductivity published in 2000–2001 that are related, fully or partially, to specific heat, whether theoretical or experimental. Records are exported from a bibliographic database as CSV, cleaned and flagged with keyword searches, screened in batches against a written rubric, and returned as a table that a human reviewer checks. The model only judges the records it is given; it never supplies references, so no citation comes from its memory.
The repository has four main pieces. `prepare_batches.py` reads a Web of Science or Scopus export, keeps the chosen years, removes duplicates, flags records that mention specific heat or superconductivity, and writes `candidates.csv` plus numbered batches of records. `criteria.md` defines the rubric (a 0–3 specific-heat score, the date range and the study type), and `prompts/screen.md` holds the instructions sent to the model. `pipeline.py` sends each batch to the Anthropic API, asks for a JSON answer, checks that the model returned exactly the records it was sent, and merges the results into `screening/screening_results.csv`, with a `needs_check` column and an empty `human_decision` column for the reviewer.
To run it, install `pandas` and `anthropic`, set the `ANTHROPIC_API_KEY` environment variable (the key is never stored in the code), run `python prepare_batches.py records.csv`, and then `python pipeline.py --dry-run` to preview a prompt before using `--limit 2` for a small test. The fixed part of the prompt is marked for caching, and saved results are tied to a fingerprint of the prompt, criteria and model, so changed instructions are never mixed with old results. The workflow has limits: the model sees only titles and abstracts, so papers that report specific heat as a secondary measurement may be flagged for full-text review, and every included paper should be read by a person. The exported records are not included in this repository, because database licenses may restrict redistribution.
